# Kidoo Community third-party review

Reviewed 3 November 2026 for the current Community source and the Android TV 0.2.0 unsigned release build. This is a technical rights and provenance review, not a legal opinion or blanket permission to distribute every possible build. The [Community licence](../LICENSE) applies only to material the project owner can license; third-party terms continue to apply.

## Android runtime and font

- **Runtime libraries:** Gradle resolved 46 release runtime artifact records representing 45 unique component/artifact records. Cached Maven POMs or parent POMs declare Apache-2.0 for those components. Their exact filenames and SHA-256 hashes are in the [runtime CycloneDX inventory](third-party/android-release-runtime.cdx.json). This is not a complete application or build SBOM: it excludes app assets, build and test dependencies, the Android platform and external tools. The metadata declarations are evidence, not proof of every underlying file's licence. See the [release component table](ANDROID-RELEASE-RIGHTS-REVIEW.md).
- **Notices:** The 45 unique cached release runtime archives were inspected for named licence and notice files, including nested JARs in AARs. AndroidX Leanback and RecyclerView contain Apache licence files; OkHttp contains a Public Suffix List notice. The rebuilt unsigned APK contains the Apache, MPL and Outfit licence texts, Kidoo's third-party notice and OkHttp's own notice. Apache-2.0 redistribution requirements include supplying the licence and retaining applicable notices; inspect the actual release and its dependencies each time. [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).
- **Outfit font:** `android-tv/app/src/main/res/font/outfit.ttf` has SHA-256 `fc7287273e66929776e2ba54f144fe699080bec29f61bf649d70d871468aeade` and matches the [Google Fonts copy at pinned revision 2fe1e8c6](https://github.com/google/fonts/blob/2fe1e8c6b137fb13041a7cfca6fdcd8a910ea4dc/ofl/outfit/Outfit%5Bwght%5D.ttf) byte for byte. Copyright 2021 The Outfit Project Authors; [SIL OFL 1.1](https://openfontlicense.org/open-font-license-official-text/) applies. The upstream copyright and licence text is included in the APK and source tree. Keep that notice with distributed copies, observe reserved-name conditions for modified fonts, and do not sell the font by itself.
- **OkHttp Public Suffix List:** The compiled list in the cached OkHttp 4.12.0 JAR and unsigned APK has SHA-256 `9af43e9995ec749e7a30eec4e5a87770d7e2027847084a07cca82060eff0c791`. It matches the file in OkHttp source revision `4984568367caaf359b82c452bd28b5e192824d1c`. The [source list at that revision](https://github.com/square/okhttp/blob/4984568367caaf359b82c452bd28b5e192824d1c/okhttp/src/test/resources/okhttp3/internal/publicsuffix/public_suffix_list.dat) has SHA-256 `e8b273972eb5a70e888bd3e7d7c5b9b04e600a59d69def9136a74d70ae6fcdd3`. Parsing, sorting and encoding its 9,499 normal and eight exception rules reproduced the complete uncompressed data in the compiled file. The [generator](https://github.com/square/okhttp/blob/4984568367caaf359b82c452bd28b5e192824d1c/okhttp/src/test/java/okhttp3/internal/publicsuffix/PublicSuffixListGenerator.java) documents that transformation. OkHttp identifies the list as MPL 2.0. The bundled notice identifies the exact source; ensure executable recipients can actually access the corresponding source under [MPL 2.0 section 3](https://www.mozilla.org/en-US/MPL/2.0/), and recheck whenever the dependency changes.

## Images and other material

- **README demonstrations:** Dashboard screenshots use fictional records. The Your TV screenshot uses fictional labels and illustrations from the isolated app. The TV-home screenshot contains a still from *Big Buck Bunny*, © 2008 Blender Foundation, [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/), attributed in the README. No film is bundled. The previous rights review recorded the film's Blender provenance; the original project attribution page was unavailable during this review, so retain independent evidence before a release relying on it.
- **Kidoo branding:** The owner stated that they created the logo. This review did not establish trademark clearance or independently verify rights in any elements used to create the logo. User-supplied movie and series artwork is not licensed by Kidoo.
- **Gradle wrapper:** The tracked `android-tv/gradle/wrapper/gradle-wrapper.jar` contains `META-INF/LICENSE` with Apache-2.0 text; its SHA-256 is `81a82aaea5abcc8ff68b3dfcb58b3c3c429378efd98e7433460610fecd7ae45f`. The configured Gradle distribution has its own checksum in the wrapper properties. The wrapper is a build-time component; this check is not a full audit of Gradle or its plugins.
- **Server and optional tools:** The current server imports Python standard-library modules; Python itself and platform-provided components have their own terms. Jellyfin is an independently installed service. The optional real-media test calls a separately installed FFmpeg; FFmpeg is not bundled here. If a future package redistributes FFmpeg, review the exact version, configuration, corresponding source and applicable LGPL/GPL obligations. [FFmpeg's legal guidance](https://ffmpeg.org/legal.html) explains why the build configuration matters. The Community checkout does not bundle yt-dlp or Deno.

## Before distributing a release

1. Build the exact signed artifact; regenerate an inventory for that artifact and audit actual bundled notices, licence texts, binaries and source availability. Build, test, platform and installer dependencies need their own scope. A current inventory cannot establish compliance for a later release.
2. Ensure recipients can read the notices and obtain the identified matching MPL source. Preserve the exact source and evidence if an upstream host changes. Confirm the applicable obligations for the chosen distribution method and jurisdiction with qualified counsel.
3. Review rights for any replacement artwork, demonstration media and logos. The former repository and its pull-request references are now private. Previously public material may remain in caches or third-party copies; this review does not remove or license those copies.
4. Update this review whenever dependencies, media, bundling, the build configuration or distribution method change. If outside contributors are accepted, establish their rights before including their material.
