# Repository working practices

- Use the maintained clean checkout as the primary working tree for this repository. Do not use an archived prototype checkout for current development or publishing.
- Before publishing, review changes and history for personal data, credentials, private network addresses, viewing records and other family-specific information. Keep those in local configuration and data files, never in the repository.
- Preserve unrelated local changes and clearly distinguish tested features from planned or incomplete ones in documentation.
- Before starting any test playback on a TV or other device, set the connected audio output to its minimum volume. If you cannot control or verify the volume, ask the user to lower it before starting playback.
